# Rockman

这是一个基于 Unity 开发的 2D 横版动作游戏，也是我的本科毕业设计。

这个项目从 **2025 年 4 月**开始开发。当时我从零开始自学 Unity，希望在学习游戏开发的同时，尝试亲手复刻自己一直很喜欢的《洛克人》系列，于是开始了这个项目。

开发过程中，我一边学习 Unity 和游戏开发相关知识，一边逐步完成游戏内容。玩家可以进行移动、跳跃、攻击、冲刺等操作，并通过击败 Boss 获得新的能力和武器。

目前游戏包含 **7 个关卡、22 种普通敌人和 7 个 Boss**，同时完成了角色控制、战斗、武器、敌人 AI、Boss 战、角色能力切换、UI 和关卡流程等主要功能。

目前项目的核心内容已经基本完成，剩余工作主要是一些早期开发阶段留下的细节优化。
